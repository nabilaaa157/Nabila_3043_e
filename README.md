# Tugas-Slicing-Website

Nabila Catering merupakan website yang dibuat untuk menampilkan paket catering dan membantu pengguna menghitung estimasi harga berdasarkan paket dan jumlah porsi.

Teknologi yang digunakan adalah HTML, CSS, dan JavaScript.

Terdapat beberapa fitur, yaitu:
- Tampilan berbagai paket catering
- Form pemesanan
- Perhitungan estimasi total harga secara otomatis
